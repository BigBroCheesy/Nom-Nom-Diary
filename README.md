# 🍓 Nom Nom Diary

A cute pink doodle-style meal price tracker. Pure HTML/CSS/JS — no build step, no dependencies.

## Run locally (VS Code)
1. Put `index.html`, `style.css`, `script.js` in one folder and open it in VS Code.
2. Install the **Live Server** extension, right-click `index.html` → *Open with Live Server*.
   (Or just double-click `index.html`.)

## Deploy free on GitHub Pages
1. Create a new GitHub repo (e.g. `nomnom-diary`), set it to Public.
2. Upload the files (or `git init`, `git add .`, `git commit`, `git push`).
3. Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
4. After a minute your link will be `https://<your-username>.github.io/nomnom-diary/`.

## Good to know
- Data is saved in the browser (localStorage) on each device. Use **⚙️ Settings → Backup / Restore** to move or protect it.
- Currency, name and monthly budget can be changed in Settings.
